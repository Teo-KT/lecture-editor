# HTML Visual Editor v3.2.1

강의 자료 HTML을 브라우저에서 시각적으로 편집하는 단일 파일 에디터입니다. GitHub Pages에 올리면 어디서나 사용할 수 있습니다.

## 새로 추가된 기능 (v3.2 → v3.2.1)

- **PDF 내보내기 전면 수정**: 슬라이드 덱(1920×1080, reveal.js)의 PDF 내보내기가 이제 **슬라이드 전체를 1장 = 1페이지**로 저장합니다.
  기존에는 덱 자체의 인쇄 CSS에 의존해서, 인쇄 CSS가 없는 덱은 현재 슬라이드 한 장만 저장됐고, 있어도 슬라이드가 페이지 경계에서
  둘로 쪼개지곤 했습니다. 이제 에디터가 인쇄 전용 사본(전 슬라이드 펼침 + @page 크기를 슬라이드 크기로 고정 + 덱 내비 스크립트 제거)을
  만들어 인쇄 대화상자를 엽니다. 인쇄 창에서 "PDF로 저장"을 고르면 됩니다.
- **슬라이드 삭제**: 상단 내비의 🗑 버튼(현재 슬라이드), "슬라이드 순서" 패널 각 줄의 ✕, 우클릭 메뉴의 "현재 슬라이드 삭제",
  또는 슬라이드 섹션을 선택하고 Del. 모두 ⌘/Ctrl+Z로 되돌릴 수 있고, 마지막 남은 한 장은 지워지지 않습니다.

## 새로 추가된 기능 (v3.1 → v3.2)

- **캔버스 우클릭 메뉴**: 요소 위나 빈 곳에서 우클릭하면 텍스트 편집, 바깥 요소 선택, 같은 상자 안 모두 선택, 슬라이드 전체 선택,
  도형 삽입(우클릭한 자리에), 요소 삽입, 복제·복사·붙여넣기, 배치(맨 앞/뒤, 한 단계), 정렬·이동(가로·세로 가운데, 상하좌우 맞춤), 삭제가 뜹니다.
- **전체 선택·복사·붙여넣기**: ⌘/Ctrl+A(슬라이드 전체), ⌘/Ctrl+C·V(에디터 안 복사/붙여넣기), ⌘/Ctrl+D(복제). 여러 개를 선택한 채 드래그·화살표로 함께 움직이고 Del로 한꺼번에 지웁니다.
- **정돈된 사이드바**: "채우기·테두리 / 글자 / 위치·크기·여백" 세 묶음으로 정리했고, 테두리는 굵기·선 종류·색(스와치+HEX)이 한눈에 보입니다.
  글꼴·크기·색·간격 조절은 도구모음에서 사이드바로 옮겼고, 텍스트·CSS 직접 편집과 편집 이력은 "고급" 아래로 접어 두었습니다.
- 도형은 현재 슬라이드 안에 삽입되어 저장 후에도 그 슬라이드에만 남습니다. 삭제는 확인창 없이 바로 지우고 ⌘/Ctrl+Z로 되돌립니다.

## 새로 추가된 기능 (v3 → v3.1)

- **슬라이드 순서 변경**: 1920×1080 덱(presentation-html-deck)과 reveal.js 파일에서 슬라이드 순서를 바꿉니다.
  - 상단 슬라이드 번호 칩을 **드래그**해서 원하는 위치에 놓기
  - 우측 **"슬라이드 순서"** 패널에서 제목을 보며 드래그하거나 **▲▼** 클릭
  - 상단 **⇠ ⇢** 버튼 또는 **Alt+PageUp / Alt+PageDown** 으로 현재 슬라이드를 한 칸씩 이동
  - 실행취소(Ctrl/⌘+Z)로 되돌릴 수 있고, 저장하면 바뀐 순서가 그대로 파일에 반영됩니다.
- **구글 드라이브 연동**: **☁ 드라이브** 메뉴에서 드라이브의 HTML 파일을 골라 열고, 편집 후 **같은 파일에 저장**합니다.
  아래 "구글 드라이브 연동" 절을 참고하세요.

## 새로 추가된 기능 (v2 → v3)

- **도형 추가**: 사각형, 원, 선, 화살표, 텍스트박스를 클릭 한 번으로 삽입 → 드래그로 이동, 핸들로 크기 조절, 색상 변경.
- **크기 조절 핸들**: 선택한 요소·이미지·도형에 8방향 핸들이 나타나 드래그로 크기 조절(이미지는 비율 유지).
- **이미지 개선**: 삽입·드래그앤드롭에 더해 **붙여넣기(Ctrl+V)** 지원, 핸들 리사이즈.
- **스타일 패널**: 글자색·배경색·글자크기·폰트·굵기·정렬·여백·모서리·테두리를 클릭으로 즉시 변경.
- **요소 추가**: 표(2×2), 구분선(hr), 버튼 삽입.
- **URL로 불러오기**: 주소를 입력해 원격 HTML을 바로 편집(동일 출처/CORS 허용 파일).
- **내보내기**: PDF(인쇄 대화상자) 및 PNG 이미지로 저장.
- 기존 기능(파일 열기·저장, 텍스트 편집, 드래그 이동, 국/영 토글·슬라이드 처리, 실행취소/재실행)은 그대로 유지됩니다.

## 사용법

1. `index.html`을 브라우저(Chrome 권장)에서 엽니다.
2. 좌상단 **열기**로 편집할 HTML 파일을 불러옵니다(또는 **URL 열기**).
3. 상단 도구모음에서 도형/요소/이미지 삽입, 우측 **스타일** 패널로 서식 변경, 선택 후 핸들로 크기 조절.
   - 글상자를 클릭하면 안쪽 글자 요소가 잡힙니다. 상자 자체를 늘이거나 옮기려면 우측 "선택된 요소" 아래 **경로 칩**에서 바깥 요소를 고르거나 **Alt+↑**(도구모음 ⬆)를 누르세요.
   - 크기 조절은 flex 카드·인라인 요소·max-width가 걸린 상자에도 적용됩니다(드래그 시작 시 해당 제약을 인라인 스타일로 풉니다).
4. **저장**(같은 파일에 덮어쓰기, Chrome) 또는 **다운로드**로 결과 HTML을 내보냅니다.

> 저장(덮어쓰기)은 Chrome의 File System Access API를 사용합니다. 파일을 **열기**로 불러온 뒤 **저장**하면 원본 파일에 바로 반영됩니다.
> 드라이브에서 연 파일은 **저장** 시 드라이브의 같은 파일에 덮어씁니다(이전 판은 드라이브 "버전 기록"에 남습니다).

## 구글 드라이브 연동

**☁ 드라이브 → 드라이브에서 열기**를 누르면 구글 로그인 후 구글의 파일 선택창(Picker)이 뜹니다.
파일을 고르면 에디터에 열리고, 이후 **저장(Ctrl/⌘+S)** 또는 **☁ 드라이브 → 드라이브에 저장**으로 같은 파일에 반영됩니다.
다른 곳에서 파일이 바뀐 뒤라면 덮어쓰기 전에 확인을 받습니다.

### 보안 설계

- **최소 권한(`drive.file`)**: 에디터는 사용자가 선택창에서 직접 고른 파일에만 접근합니다. 드라이브의 다른 파일은 목록조차 볼 수 없습니다.
  이 범위는 구글이 "민감하지 않은" 범위로 분류하므로 별도 앱 심사가 필요 없습니다.
- **토큰은 메모리에만**: 액세스 토큰은 localStorage·쿠키에 저장하지 않고 페이지 메모리(클로저)에만 두며 1시간 안에 만료됩니다.
  **연결 해제** 메뉴는 토큰을 즉시 폐기(revoke)합니다.
- **지연 로드**: 구글 라이브러리는 드라이브 버튼을 눌렀을 때만 불러옵니다. 드라이브를 쓰지 않는 사용자는 외부 스크립트를 로드하지 않습니다.
- **공개 식별자만 저장소에 둡니다**: `drive-config.js`의 CLIENT_ID · API_KEY · APP_ID는 비밀값이 아닙니다.
  OAuth 클라이언트는 승인된 원본(`https://teo-kt.github.io`)에서만, API 키는 **HTTP 리퍼러 제한**을 건 상태에서만 동작하도록 설정해 두어야 합니다.
- **파일 내용은 브라우저와 구글 사이에서만 오갑니다**. 이 사이트에는 서버가 없어 파일이 제3자에게 전송되지 않습니다.
- 주의: 에디터는 열린 HTML의 스크립트를 미리보기 프레임에서 실행합니다(로컬 파일과 동일). 출처를 모르는 HTML은 드라이브에서도 열지 마세요.

### 설정 (본인 GCP 프로젝트를 쓰려면)

1. [Google Cloud Console](https://console.cloud.google.com/) → **API 및 서비스 → 라이브러리**에서 **Google Drive API**, **Google Picker API** 사용 설정.
2. **사용자 인증 정보 → API 키** 생성 → **애플리케이션 제한: HTTP 리퍼러**에 `https://<사용자명>.github.io/*` 추가, **API 제한**을 Drive API·Picker API로 한정.
3. **OAuth 클라이언트 ID(웹 애플리케이션)** 생성 → **승인된 자바스크립트 원본**에 `https://<사용자명>.github.io` 추가(리다이렉트 URI 불필요).
4. **OAuth 동의 화면**이 "테스트" 상태라면 **테스트 사용자**에 본인 계정 추가. (테스트 상태 동의는 7일마다 갱신됩니다.)
5. `drive-config.js`에 세 값을 채웁니다. 비워 두면 드라이브 버튼은 안내만 표시하고 나머지 기능은 그대로 동작합니다.

> 드라이브 연동은 `http(s)`로 접속했을 때만 동작합니다. `file://`로 직접 연 경우에는 안내 메시지가 뜹니다.

## GitHub Pages 배포 (요약)

1. GitHub에서 새 저장소 생성 (예: `lecture-editor`, Public).
2. `index.html`과 `drive-config.js`를 저장소 루트에 업로드.
3. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root)** 저장.
4. 1~2분 뒤 `https://<사용자명>.github.io/lecture-editor/` 에서 접속.

> 공개 저장소이면 에디터 자체는 누구나 접근할 수 있지만, 여러분의 로컬 강의 파일은 올라가지 않습니다. 에디터에서 **열기**로 로컬 파일을 불러와 편집하고 **저장/다운로드**하는 방식이라 자료는 로컬에만 남습니다.
