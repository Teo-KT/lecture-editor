사용 방법

1. 파일 열기 — 📂 버튼 또는 Ctrl/⌘+O로 HTML 파일을 엽니다.
2. 요소 선택 — 선택 모드(V)에서 요소를 클릭하면 파란 테두리로 선택됩니다.
3. 텍스트 편집 — 편집 모드(T)에서 텍스트를 직접 클릭하여 수정합니다.
4. 속성 변경 — 우측 패널에서 색상, 크기, 간격 등을 조정합니다.
5. 토글 제어 — 더블클릭으로 토글 요소를 펼치고 접습니다. 우측 패널에서 일괄 제어 가능합니다.
6. 저장 — 💾 버튼 또는 Ctrl/⌘+S로 수정된 HTML을 저장합니다.
